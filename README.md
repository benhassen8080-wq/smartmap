# خريطتي الذكية – Web App (PWA)

تطبيق ويب يعمل على iPhone و Android وأي حاسوب، ويُثبَّت كأيقونة على الشاشة الرئيسية.

**التثبيت على iPhone:** افتح الرابط في Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».

- خريطة: عادية، هادئة، قمر صناعي، هجينة، ليلية، تضاريس
- طقس بستة نماذج (منها ECMWF AIFS للذكاء الاصطناعي) + رادار + سحب + جودة الهواء + تحذيرات DWD
- طائرات حيّة (ADS-B)، أقمار صناعية (SGP4)، سفن (AIS)، مناطق الدرون والقوانين
- كاميرات مفتوحة، ثقافة، أسواق و Flohmarkt، حيوانات، حرائق، زلازل، رادارات السرعة (حسب القانون)
- قوانين 28 دولة تتغير تلقائياً حسب مكانك
- خريطة طوارئ تعمل دون إنترنت + SMS بالموقع + إشارة SOS
- إرشاد بالكاميرا، أوضاع القيادة/الدراجة/المشي/الطائرة
- بحث ذكي بالعربية/الألمانية/الإنجليزية + Claude اختياري
- سجل خاص مشفّر AES-256 على الجهاز فقط، روتين واقتراحات

لا خوادم، لا حسابات، لا تتبّع. كل البيانات الشخصية تبقى على جهازك.
